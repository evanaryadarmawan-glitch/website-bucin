# 🎂 Website Ultah Romantis

Website interaktif khusus untuk merayakan ulang tahun orang tersayang.

## Cara Pakai

1. **Ganti sandi**  
   Buka `index.html`, cari baris:
   ```js
   const CORRECT_PASSWORD = "sayang";
   ```
   Ganti `"sayang"` dengan sandi yang kamu mau.

2. **Tambah audio**  
   Letakkan file musik di folder yang sama (contoh: `music.mp3`).  
   Di HTML sudah disiapkan:
   ```html
   <source src="music.mp3" type="audio/mpeg">
   ```
   Ganti nama file sesuai yang kamu upload ke repository.

3. **Ganti nama / teks**  
   Cari kata "Sayangku", "Dari Aku", surat cinta, timeline, dll. sesuaikan dengan yang kamu mau.

4. **Upload ke GitHub / Netlify / Vercel**  
   Cukup upload semua file (index.html + foto + music.mp3).

## Fitur yang Ada

- 🔐 **Password gate** (harus masukkan sandi dulu)
- 🎵 **Auto-play musik** setelah masuk (bisa di-toggle)
- 📱 **Layout mobile-first** (bagus di HP)
- ⏰ **Countdown** ke tengah malam
- 💘 **Love Meter** interaktif (isi sampai 100% + overflow)
- 🎂 **Kue virtual** — tiup lilinnya, ada asap & confetti
- 🖼️ **Gallery foto** + lightbox
- 💌 **Surat cinta**
- 🎉 **Confetti explosion**
- 💕 **Hujan hati**
- ⭐ **Photo booth strip**
- 📅 **Timeline kenangan**
- ❓ **Mini quiz interaktif**
- 💬 **Tombol ucapan** yang muncul toast
- ✨ Banyak animasi soft & romantis
